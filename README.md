# Otteluohjelmavertailu

Otteluohjelmavertailu on Veikkausliigan Futismanageria varten tehty työkalu, jolla voi vertailla joukkueiden tulevien otteluiden vaikeutta.

Sovellus järjestää joukkueet helpoimman tai vaikeimman otteluohjelman mukaan ja näyttää seuraavat ottelut värikoodattuina.

## Ominaisuudet

- Tulevien otteluiden vertailu
- Helpoin / vaikein otteluohjelma
- A–Ö-järjestys
- Kotona- ja vieraspelit merkattu `(K)` ja `(V)`
- Mobiiliystävällinen käyttöliittymä
- Värikoodatut fixture difficulty -ratingit

## Miten difficulty rating toimii?

Ottelun vaikeus perustuu tällä hetkellä vastustajan sarjapisteisiin, tehtyihin ja päästettyihin maaleihin sekä koti-/vierasetuun.
